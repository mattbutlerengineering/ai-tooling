## What it does

A curated list of AI tools aimed at building UI and UX — design-side tooling rather than
coding-agent tooling.

## How we tested it

**Evidence:** SOURCE-ONLY

We did **not** install or run this — it is a list. Source-grounded only: GitHub metadata (fetched
2026-08-04) plus the CATALOG one-liner and "Overlaps with" cell (`awesome-claude-code`,
`awesome-agent-skills`). Sufficient for a SKIP that turns on *scope*; not sufficient for a positive
verdict, and none is offered.

## Verdict

**SKIP** — off-scope, and the weakest directory in the Reference section on every measurable axis.

This catalog maps tools that move a quality signal in the *dev loop* — Plan, Implement, Verify,
Review, Ship, Reflect. AI tools for designing beautiful UI/UX are a design-practice category; the
dev-loop slice of that question (does the agent produce correct, accessible frontend code) is
already held by `web-quality-skills` in STACK and by the `generative-ui-frameworks` cluster eval.

The supporting facts leave nothing to weigh against the scope call: ★736 — an order of magnitude
below every other list in this section — and no declared licence, on a resource whose only content
is curation.

Re-open if this catalog widens to cover design tooling, where a dedicated list would be the right
starting point.
