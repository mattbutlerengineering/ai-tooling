## What it does

A curated, YAML-driven catalog of Open Knowledge Format resources — 4 tools/CLIs, 7 producer plugins (GitHub/Obsidian/Notion/Feishu extraction), 7 Claude Code skills, 5 protocol proposals/extensions, and 6 documentation/spec resources. Exposes the catalog itself via an `awesome-okf-server` MCP server so agents can query it directly.
