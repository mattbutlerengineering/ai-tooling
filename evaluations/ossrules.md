## What it does

Collects real `AGENTS.md`/`CLAUDE.md`-style agent instruction files from open-source repositories,
analyzes their patterns, and makes them searchable as a reference library — for a developer writing
their own project's instruction file who wants to learn from real-world conventions instead of
guessing.
