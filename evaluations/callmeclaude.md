## What it does

A voice-first, self-hosted supervisor (Mac hub + iPhone app) that calls you by phone when a
Claude Code agent gets stuck, instead of leaving you to poll the terminal.

## How we tested it

**Evidence:** SOURCE-ONLY

We did **not** install or run this tool. This evaluation is source-grounded only: the CATALOG
one-liner and its "Overlaps with" cell (`t3code`, `CodeRail`, `agent-of-empires`). That is

this eval offers none.

## Verdict

**discovery-log — tentative read** — none of its cited peers is a STACK pick, and the "proactive
voice call when stuck" notification pattern is distinct from the remote-control/dashboard tools
it is loosely grouped with here (those let you check in; this one calls you first). Worth a real
hands-on eval.
