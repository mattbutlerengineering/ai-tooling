## Verdict

**SKIP** — gone. Not stale, not superseded: the resource this row describes no longer exists, and
the link resolves to an unrelated project.

This is the failure mode a link-rot check cannot catch on its own. A 404 reads as dead and a rename
reads as moved, but a *repurposed* repo returns 301 to a live page — so the sweep reports it as
`MOVED` and a mechanical repoint would silently aim a Hermes Agent reference at a
content-monetization curriculum. The row survives as a tombstone precisely so that mistake is not
made twice; the ⚠️ note is load-bearing.

The cached metadata under this slug is worth distrusting for the same reason: `repo-metadata.json`
records MIT / ★1,810, and those are the *destination's* facts, arriving through the redirect. They
say nothing about the list that used to be here.

Nothing to re-open. If the Hermes Agent ecosystem needs an index again, it will be a different repo
and a different row — `hermes-agent` and `hermes-webui` are the catalogued entries that remain.
