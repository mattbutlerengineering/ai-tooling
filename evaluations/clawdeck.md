## What it does

An ambient Claude Code status panel for the Corsair Xeneon Edge — an iCUE widget plus a
local companion app (Windows) that shows session status on dedicated hardware instead of a
window you have to switch to.

## How we tested it

**Evidence:** SOURCE-ONLY

We did **not** install or run this tool. This evaluation is source-grounded only: repo
metadata plus the CATALOG "Overlaps with" cell. That is sufficient for a SKIP that turns on
redundancy with a catalogued incumbent, not on the tool's behaviour — a question the overlap
answers directly. It would not support an ADOPT, and this eval offers none.

## Triage note

Left at `discovery-log`: no structural disposition applies — none of ai-pulse/ping-island/
claude-nanny are STACK picks, and Clawdeck's niche (specific Corsair hardware, Windows-only)
is narrower than any of them. A real ambient-status tool, but hardware-gated adoption makes
it a low-priority backlog item rather than a SKIP or a promotion candidate.
