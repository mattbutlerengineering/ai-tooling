Databricks, Kafka, Iceberg) as portable SKILL.md files, usable across Claude Code, Cursor, Codex,

## How we tested it

**Evidence:** SOURCE-ONLY

We did **not** install or run this tool. This evaluation is source-grounded only: GitHub repo
metadata (license, description, topics). That is sufficient for the verdict below, because the
verdict turns on the license bar, not on the tool's behaviour. It would not be sufficient to
support an ADOPT, and this eval offers none.

## Verdict

**SKIP** — no clear OSS license. GitHub's licensee detector reports `NOASSERTION` (a LICENSE file
exists but GitHub could not identify a recognized license from it), and this is a vendored
skill Type — text copied into the consuming repo, so an unclear license grant blocks adoption the
same as a missing one. Re-evaluate if the repo adopts a standard, machine-detectable OSS license.
