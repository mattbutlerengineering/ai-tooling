## What it does

An agent-agnostic development environment ("Agent Context Relay Yielding Lifecycles") giving any coding agent one persistent workspace and canonical context, with desktop, TUI, and CLI surfaces. Built around "Cordis," a plugin-lifecycle meta-framework, with lineage from DeepSeek Harness (included as a read-only submodule).
