## What it does

Analyzes real Codex and Claude Code sessions to find repeated workflow patterns and turns them into reusable skills, checks, prompts, and recommendations — a continuous-improvement layer over coding-agent session history.

## How we tested it

**Evidence:** SOURCE-ONLY

We did **not** install or run this tool. This evaluation is source-grounded only: repo metadata
(license, description, topics) plus the CATALOG "Overlaps with" cell. That is sufficient for the
verdict below, because the verdict turns on *license*, not on the tool's behaviour. It would not
support an ADOPT, and this eval offers none.

## Verdict

**SKIP** — AGPL-3.0. This run's license bar disqualifies copyleft: only permissive, MIT-like OSS is
adoptable for this catalog. AGPL-3.0 imposes network-use copyleft obligations that a permissive-only
adoption policy is not prepared to take on, independent of whether the artifact would otherwise be
vendored. `hivemind` and `getspecstory` already cover the "mine sessions into reusable skills" job
in Memory & Context under permissive terms.

_Triaged 2026-09-05 under this run's license bar (copyleft or missing license ⇒ SKIP), stated in
the scheduled discovery-and-triage task's hard rules._
