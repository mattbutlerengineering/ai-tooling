rehearsal, and managing nerves. Not deck generation.

## How we tested it

**Evidence:** SOURCE-ONLY

We did **not** install or run this. Source-grounded only: GitHub metadata (fetched 2026-08-04) plus the
CATALOG one-liner and "Overlaps with" cell. Overlaps cited: `slidev`, `powerpoint`,

## Verdict

**SKIP** — it coaches a human, not an agent, and its source collection is quiet.

The scope point needs care, because the Skills & Plugins blurb is deliberately broad — *"extensions that add
domain-specific capabilities to coding agents"* — and that admits marketing, PM, SEO and finance packs by
design. Those were all left standing in this pass. The line this row falls on the wrong side of is
different: rehearsal technique and managing nerves are not a *capability an agent exercises*. There is no
artifact and no action; the skill's whole output is advice to the person reading it.

The row's own one-liner draws the distinction — *"delivery, not deck generation"* — which is precisely what
separates it from every other presentation entry here, all of which produce something.

Dormancy corroborates rather than decides: pushed **2026-01-31**, over six months, in a collection of 86
skills where a single one is catalogued.

MIT and ★1.1K, and the underlying advice is presumably fine. It is simply not a thing this catalog's dev
loop has a place for.

Re-open if this catalog widens to cover human communication coaching.
