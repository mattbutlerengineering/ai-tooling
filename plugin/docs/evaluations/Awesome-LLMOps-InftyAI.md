## Verdict

**SKIP** — superseded by its own named twin. The catalog carries two lists called *Awesome-LLMOps*
covering the same ground; this one is the smaller by more than twenty times
([★253 vs ★5.9K](https://github.com/tensorchord/Awesome-LLMOps)), and the larger one is CC0-1.0,
which is a friendlier grant for a document people copy from.

Curated lists are the one catalog Type where a popularity gap is a genuine quality signal rather
than a vanity metric: the value of an awesome-list *is* the breadth and freshness of its curation,
and both scale with the number of people sending pull requests. Two entries for one niche means a
reader has to pick, and the answer is not this one.

Nothing is wrong with it — Apache-2.0, pushed 2026-07-10, actively maintained. It is simply the
second copy.

Re-open if the tensorchord list goes dormant, which would invert the comparison.
