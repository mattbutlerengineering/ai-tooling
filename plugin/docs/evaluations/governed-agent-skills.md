## What it does

Six governance skills for teams of coding agents — constitution, working method, minimum-sufficient implementation, planning, test evidence, and a maximum-assurance convergence cycle — plus a PreToolUse-style enforcement hook that blocks catastrophic shell commands. The core claim: "the agent that builds a thing is never the agent that approves it." Installable as a Claude Code plugin.
